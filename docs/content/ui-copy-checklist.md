# Checklist de revisão de textos da interface

Use antes de publicar qualquer tela, fluxo, notificação ou mensagem.

- [ ] Todo o texto está em português brasileiro natural?
- [ ] A ação principal é clara sem explicação adicional?
- [ ] Os botões descrevem a ação, e não apenas um estado vago?
- [ ] A mesma ação usa o mesmo verbo em todo o produto?
- [ ] O texto evita jargão e termos internos da equipe?
- [ ] O produto só confirma ações realmente concluídas?
- [ ] Se houve erro, a mensagem explica como continuar?
- [ ] O estado vazio explica o que pode ser feito?
- [ ] Resultados de busca vêm de dados reais, não de exemplos apresentados como reais?
- [ ] Está claro se o conteúdo está salvo localmente, na nuvem ou ainda não foi enviado?
- [ ] Botões e mensagens são compreensíveis com leitor de tela?
- [ ] A linguagem mantém acolhimento sem culpa, pressão ou excesso de intimidade?
