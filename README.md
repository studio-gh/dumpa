# Dumpa

**Tire da cabeça. Encontre quando precisar.**

Dumpa é uma memória pessoal digital para guardar links, prints, ideias e informações e reencontrá-los depois, sem depender de lembrar palavras exatas nem organizar tudo manualmente.

## Princípios do produto
- Primeiro reduzir a carga mental; depois adicionar recursos.
- Guardar é simples. Encontrar é tão importante quanto guardar.
- Português brasileiro claro em toda a interface.
- Não prometer funcionalidades que ainda não foram construídas e testadas.
- Privacidade, persistência dos dados e confiança fazem parte da experiência, não são extras.

## Estado atual
Repositório inicial do MVP. O nome Dumpa é provisório até a verificação formal de domínio e marca no INPI.
